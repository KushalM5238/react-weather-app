# SkyCast

A modern weather app built with React.js that shows real-time temperature, dynamic weather condition icons, wind speed, and humidity using a weather API.

## Features
- Real-time temperature
- Weather condition icons
- Wind speed
- Humidity

## Tech Stack
- React.js
- CSS
- Weather API
